# 智能 PDF 题库导入

智能 PDF 题库导入会从用户选择的 PDF 中识别面试题，生成适合复习的答案和 Markdown 思维导图，并写入 Anki。

## 使用前准备

1. 在系统设置中配置项目已有的模型服务。导入任务使用 Agent 的“步骤执行”模型设置，不会固定某个模型或服务商。
2. 安装并打开 Anki 与 AnkiConnect。后端默认访问 `http://localhost:8765`。
3. 如需生成项目相关要点，先在知识库中以“项目 GitHub 仓库”类型填写仓库 URL。系统会克隆仓库、向量化代码，并以仓库名和用户 ID 建立独立代码库。

## 导入 PDF

在“集成面试题库和 Anki”页面的“智能 PDF 题库导入”区域中：

1. 可选地选择一个已导入的项目代码库。未选择时只生成通用面试题，不会编造项目经验。
2. 点击“选择 PDF”。可以多次选择，文件会追加到带边框的列表；单个文件和全部文件都可以移除。
3. 点击“开始导入”。任务会依次完成 PDF 解析、题目过滤、答案和思维导图生成、项目证据校验以及 Anki 上传。
4. 运行中可点击“停止导入”。失败或待复核的题目可以通过“重试失败项”再次处理。

## 去重和更新规则

- 同一用户下，去除空白和标点差异后的题目全文相同，即视为同一道题。
- 规则跨 PDF、技术点和 Anki 卡组生效；重跑不会新增重复卡片。
- PDF 导入使用独立的 Anki 笔记类型 `PDF 智能题库`。隐藏的首字段保存稳定导入键，因此不会受普通题库“笔记”字段为空的影响。
- 再次导入同题时会更新已有题目的答案、项目要点和思维导图。

## 项目上下文如何读取

代码库导入使用仓库 URL，而非客户端本地路径。后端从 URL 得到仓库名，克隆到当前用户的服务端项目目录后向量化。PDF 导入只传递所选知识库记录 ID，后端重新校验归属并从原始仓库 URL 计算仓库名，再检索对应的代码向量命名空间。

只有检索结果中包含可验证的文件路径或代码标识时，模型才会输出项目要点；向量库未配置、项目尚未向量化或检索失败时，导入仍会继续，但项目要点为空。

## 运维配置

- `PDF_QUESTION_BANK_MAX_FILE_SIZE`：单个 PDF 最大字节数，默认 100 MiB。
- `PDF_QUESTION_BANK_UPLOAD_DIR`：上传文件的临时目录。未配置时使用操作系统临时目录。
- `PDF_QUESTION_BANK_IMPORT_CONCURRENCY`：题目并发处理数量，默认 2。

上传目录只保存本次任务所需的 PDF，用于失败项重试；不要将任何个人固定路径或默认 PDF 写入配置。
